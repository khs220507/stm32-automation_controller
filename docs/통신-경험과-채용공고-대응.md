# 지금까지 한 것과 채용 공고 대응

2026-09-09 기준. 코드와 기존 기록을 정리한 요약이며 공식 시험 판정은 아니다.

## 해본 통신

| 통신 | 한 것 |
|---|---|
| UART | STM32와 PC 사이에서 명령을 받고 센서값을 보내기 |
| I2C | 센서 설정 읽기·쓰기, 가속도 XYZ 읽기, 통신 오류와 시간 초과 처리 |

SPI, CAN, RS-485, Ethernet은 아직 하지 않았다. USB는 ST-LINK 연결에 사용했으며 USB 통신 코드를 직접 만든 것은 아니다.

## 공고에 필요한 것 중 해본 것

| 공고 항목 | 지금까지 한 것 |
|---|---|
| C 기반 베어메탈 | 레지스터 제어, 비트 연산, 포인터·구조체, 센서 코드 구현·분석 |
| STM32·ARM | NUCLEO-F401RE에서 GPIO, UART, I2C, 타이머 사용 |
| 센서 데이터 처리 | 가속도 XYZ 읽기·양수/음수 변환·g 단위 표시, 초음파 거리 계산 코드 |
| 타이머 | 시간 측정·시간 초과 처리, 초음파 Echo 펄스 폭 측정 코드 |
| 상태 제어 | 초기화·대기·운전·정지·오류 상태의 기본 구조 |
| 통신 오류 처리 | 센서 무응답, 설정 불일치, 읽기 실패 시 오류 반환 |
| 데이터시트 확인 | 핀, 클록, 센서 설정과 코드 대조 |
| 디버깅 | ST-LINK, 중단점·레지스터 관찰, LED 동작 확인 |
| 계측 | 로직 분석기와 PulseView로 I2C 식별값 읽기 파형 확인 |
| PC 연동 | WPF로 실제 가속도 표시·정지·재연결 확인 |
| 기록 관리 | Git, 개발 기록, 파형 파일, 측정 로그와 시험 결과 보관 |

구현·분석 경험을 포함한 표다. 모든 항목을 혼자 작성하거나 실제 보드에서 전부 검증한 것은 아니다. I2C·가속도 등의 코드는 Codex 구현 지원을 받아 함께 분석했다. 사용자가 직접 수행한 GPIO·디버깅·I2C 파형 측정 기록은 별도로 남아 있다.

## 아직 남은 것

- SPI 등 다른 통신
- 센서 인터럽트·DMA 방식의 데이터 수집, RTOS
- 각속도 읽기, 센서 오차 보정, 기울기·진동 경고
- 모터 제어, 제어 알고리즘과 튜닝
- 센서 고장 상황의 실제 시험과 복구 확인
- 장시간 연속 동작 시험, 전체 자동운전 통합
- IAR·Keil, AVR·TMS320 등 다른 도구·MCU 경험

현재 센서값 읽기·표시는 했지만, 산업용 제어기 전체를 완성한 단계는 아니다. 경력·학력과 실제 산업 현장 경험은 이 프로젝트로 충족했다고 쓰지 않는다.
