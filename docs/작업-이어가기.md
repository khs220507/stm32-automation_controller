# 작업 이어가기

대화를 재개할 때 가장 먼저 확인하는 진행 메모다. 사용자 결정, 완료 보고와 다음 행동을 남긴다. 공식 요구사항·시험 판정은 관리 문서를 따르며, 이 메모가 대신하지 않는다.

## 현재 위치

- 현재 과제: STM32↔PC RS-485 배선 이어가기.
- 완료한 준비: RS-485 작업을 위한 납땜 완료(2026-09-14 대화에서 사용자 보고).
- 다음 행동: 납땜한 부품과 현재 연결 상태를 기준으로 RS-485 배선 작업을 이어간다. 다른 학습 주제를 다시 고르는 단계로 되돌리지 않는다.
- 완료 조건: 실제 연결 상태를 확인한 근거를 남긴 뒤 배선 완료로 기록한다. 현재 대화에서는 배선 완료·전원 인가·통신 성공까지 확인한 것은 아니다.
- 필요한 입력: 이어서 배선을 안내할 때 기존 기록에 없는 부품의 단자 표기와 현재 연결 상태만 확인한다. 납땜 완료 여부는 다시 묻지 않는다.

## 기록 방법

- 사용자가 작업 완료, 설계 선택 또는 다음 행동을 알려주면 별도 기록 요청을 기다리지 않고 이 파일을 갱신한다.
- 위의 현재 위치를 갱신하고, 아래 이력에 날짜·결정 또는 수행 내용·근거·남은 일을 짧게 누적한다.
- 기록일과 실제 작업일을 구분한다. 사용자 보고와 도구·계측 확인을 구분하고 확인하지 않은 완료나 시험 결과를 만들지 않는다.
- 경험 요약에는 핵심 경험만 남긴다. 세부 재개 위치는 이 파일로 연결해 중복 관리를 피한다.

## 진행 이력

### 2026-09-14 — RS-485 재개 위치 정정

- 사용자가 “RS-485 배선하기로 했고 납땜도 다 했다”고 정정했다. 다음 진행은 RS-485 배선으로 정해져 있으며, 납땜은 사용자 보고 기준 완료다. 실제 납땜 작업일은 별도로 확인하지 않았다.
- Codex가 9/11 학습 계획만 보고 후속 학습 순서가 미정이라고 안내한 것은 현재 진행 위치를 반영하지 못한 설명이었다.
- 사용자가 이런 진행 내용을 계속 남기는 Markdown 기록을 요청하여 이 파일을 만들었다.
- 배선 완료 여부, 납땜 품질 검사, 전원 인가 및 RS-485 송수신 시험 결과는 이번 보고에 포함되지 않았다.
