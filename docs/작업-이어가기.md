# 작업 이어가기

대화를 재개할 때 가장 먼저 확인하는 진행 메모다. 사용자 결정, 완료 보고와 다음 행동을 남긴다. 공식 요구사항·시험 판정은 관리 문서를 따르며, 이 메모가 대신하지 않는다.

## 현재 위치

- 현재 작업: RS-485용 USART1 클록 활성화 구현 완료, 핀·통신 설정 전.
- 완료한 준비: 납땜 완료 및 AT044 TXD↔PB6(CN10-17), RXD↔PB7(CN7-21) 연결 완료(2026-09-14 사용자 보고). 전원·A/B를 포함한 전체 배선의 실물 검증을 뜻하지 않는다.
- 완료한 구현: 사용자 요청으로 Codex가 uart1_enable_clocks()와 헤더를 추가하고 main 부팅 호출 및 CMake 소스 등록을 완료했다. Debug 빌드와 생성 코드 확인 성공. 다운로드·실기 확인은 미수행이다.
- 다음 위치: PB6/PB7의 USART1 핀 설정과 통신 설정이 남아 있다. 사용자에게 작성 과제를 주지 않는다. 이미 요청한 구현 범위는 Codex가 직접 수행한다.
- 남은 실기 확인: VCC–GND/A–B 저항, TX/RX 방향, USB 변환기 구조. 점검 통과로 기록하지 않으며 실제 전원 인가·송수신 전에 다시 확인한다.

## 기록 방법

- 사용자가 작업 완료, 설계 선택 또는 다음 행동을 알려주면 별도 기록 요청을 기다리지 않고 이 파일을 갱신한다.
- 위의 현재 위치를 갱신하고, 아래 이력에 날짜·결정 또는 수행 내용·근거·남은 일을 짧게 누적한다.
- 기록일과 실제 작업일을 구분한다. 사용자 보고와 도구·계측 확인을 구분하고 확인하지 않은 완료나 시험 결과를 만들지 않는다.
- 경험 요약에는 핵심 경험만 남긴다. 세부 재개 위치는 이 파일로 연결해 중복 관리를 피한다.

## 진행 이력

### 2026-09-14 — 과제 금지 명시와 USART1 클록 구현

- 사용자가 “너가 구현해줘, 과제 하지 말라고 했잖아”라고 정정하고 규칙 반영 여부를 물었다. 기존 AGENTS.md에는 퀴즈 금지는 있었지만 과제 제시 조항이 남아 있었다. 해당 조항을 과제·숙제·코드 제출 요구 금지와 요청한 범위의 Codex 직접 구현·검증으로 교체했다.
- Src/uart1.c 및 Inc/uart1.h 추가. RCC_AHB1ENR GPIOBEN bit 1과 RCC_APB2ENR USART1EN bit 4를 숫자 시프트와 OR로 설정하고 각 레지스터를 읽어 되돌린다. main의 기존 초기화 순서를 유지하며 app_state_init() 전에 호출하고 cmake/files.cmake에 등록했다.
- 검증: cube-cmake --build --preset Debug 성공. ELF 역어셈블리에서 두 레지스터 읽기→해당 비트 OR→쓰기→읽기를 확인했다. 별도 실기 시험은 하지 않았다. 사용자의 기존 Src/spi2.c 변경을 보존했으며 빌드에는 작업 트리의 해당 변경도 포함됐다.
- 근거: [RM0368 Rev 6](references/rm0368-stm32f401xb-c-d-e-mb-reference-manual-stmicroelectronics.pdf) §6.3.9 RCC AHB1 peripheral clock enable register p.118–119 및 §6.3.12 RCC APB2 peripheral clock enable register p.122–123. PDF 페이지 동일. 핀 설정·송수신 구현은 이번 범위에 포함하지 않았다.

### 2026-09-14 — 측정 미확인 상태로 펌웨어 준비 진행

- 사용자 요청: “다음 넘어가자”. 저항 측정 결과나 점검 완료 보고는 없었다.
- 다음 작은 과제는 RS-485용 USART1 클록 활성화 함수의 사용자 작성으로 안내한다. Codex의 구현 요청으로 해석하지 않았고 펌웨어 파일은 변경하지 않았다.
- VERSION 0.1.0-draft, 요구사항 0.2-draft의 부분 승인 이력과 FW-REQ-005/019/047을 직접 재확인했다. RS-485는 사용자 요청으로 진행 중인 확장 학습이며 공식 범위·판정 변경 없음.
- 제조사 근거: RM0368 Rev 6 §6.3.9 RCC_AHB1ENR p.118–119(GPIOBEN bit 1), §6.3.12 RCC_APB2ENR p.122–123(USART1EN bit 4). 이번에 읽은 로컬 PDF는 문서 표기 페이지와 PDF 페이지가 같다.

### 2026-09-14 — A/B 케이블 직접 납땜 완료 보고

- 직접 납땜 안내 후 사용자가 “다했어 다음은?”이라고 보고했다. AT044 A/B 케이블 직접 납땜 완료의 사용자 보고로 기록한다.
- 패드 상태·절연·기계적 고정·도통 측정·반대쪽 변환기 연결을 각각 검사했다고 확대 해석하지 않는다.
- 다음은 전원 분리 상태의 육안 점검 및 VCC–TTL GND, A+–B- 저항 측정이다. 측정값과 전원 인가 결과는 아직 없다.

### 2026-09-14 — 4심 케이블 연결과 AT044 단자 제거 보고

- 사용자 보고: 케이블 심선은 총 4가닥이며 같은 색 선이 두 가닥씩 있다. 편조체도 있다. 실물 사진은 확인하지 않았다.
- 안내: 서로 꼬인 한 쌍만 A/B에 사용하고, 양 끝에서 같은 도체인지 필요하면 케이블을 기기에서 분리해 도통 측정으로 식별한다. 주황색=A+, 선택한 짝의 흰색=B-는 Codex가 제시한 구분 방법이며 실제 배선 완료를 뜻하지 않는다.
- 남는 두 심선과 편조체 끝은 각각 절연해 두는 임시 방식을 안내했다. 실드·신호 기준 접지의 최종 연결은 USB 변환기 구조 확인 전 미정이다.
- 사용자가 AT044에 달았던 것을 뺐다며 직접 납땜할지 물었다. 대화 문맥상 A/B 단자 제거로 해석했으나 제거 범위·패드 상태는 미검증이다.
- 안내: A/B 패드가 온전하면 직접 납땜할 수 있다. 전원을 모두 분리하고 케이블 끝과 패드 예비 납땜, 짧은 가열, 인접 패드 단락 확인, 케이블 외피의 별도 고정이 필요하다. 직접 납땜 완료·전원 인가·저항 측정 결과는 아직 없다.

### 2026-09-14 — TX/RX 연결 완료 보고

- 직전 추정 배선 표에 대해 사용자가 “오케이 연결함 다음”이라고 보고했다. AT044 TXD↔PB6, RXD↔PB7 연결 완료로 기록한다.
- 이는 물리 연결의 사용자 보고이며 AT044 신호 방향 검증 또는 통신 성공 보고는 아니다.
- 다음 작은 과제로 전원 분리 상태의 AT044 VCC–GND 저항 측정을 안내했다. 측정값은 아직 없으며 전원 인가를 안내하지 않았다.

### 2026-09-14 — 사용자 요청으로 TX/RX 추정안 선택

- 사용자가 Codex에게 추측해서 TX/RX 배선을 정해 달라고 요청했다.
- 임시 선택: STM32 USART1 TX=PB6(CN10-17)→AT044 TXD, AT044 RXD→STM32 USART1 RX=PB7(CN7-21).
- 가정: 모듈의 TXD 표기는 RS-485 송신용 TTL 입력, RXD 표기는 수신한 데이터의 TTL 출력이다. 제공 이미지로 입출력 방향을 확정한 것은 아니다.
- 추정과 다르면 출력끼리 연결될 수 있으므로, 배선은 전원 분리 상태로 진행하며 전원 인가·송수신 구동 전 방향 확인이 남아 있다. 펌웨어 변경·실제 배선 완료·통신 성공은 아직 없다.

### 2026-09-14 — TX/RX를 제외하고 먼저 배선

- 사용자 결정: TX/RX 연결은 제외하고 나머지 배선을 먼저 진행한다.
- 안내 범위: 전원을 분리한 상태에서 NUCLEO CN7-16(3.3V)→AT044 VCC, CN7-20(GND)→AT044 TTL 쪽 GND. PC용 변환기의 A+/B- 표기가 일치하면 AT044 A+↔변환기 A+, B-↔B-로 연결한다.
- AT044 버스 쪽 접지 기호 단자와 TXD/RXD는 이번 연결에서 비워 둔다. USB 변환기의 5V를 AT044 VCC에 추가 연결하지 않는다. 전원 인가는 배선 점검 후 별도 진행한다.
- 배선 완료·전원 인가·측정·통신 성공 보고는 아직 없다.

### 2026-09-14 — RS-485 배선 안내

- 사용자 요청: RS-485 배선을 직접 안내해 달라고 요청했다.
- Codex 제안: 기존 USART2 진단(PA2/PA3)과 초음파(PA10)를 유지하기 위해 USART1의 PB6(TX)/PB7(RX)를 사용한다. 사용자 선택·배선 완료로 판정하지 않는다.
- NUCLEO 위치: PB6=CN10-17, PB7=CN7-21, 3.3V=CN7-16, GND=CN7-20. 근거: [UM1724 Rev 17](references/dm00105823-nucleo-f401re-user-manual-stmicroelectronics.pdf), Hardware layout and configuration, Table 29 p.59; [DS10086 Rev 5](references/DS_stm32f401re.pdf), Pinouts and pin description, Table 8 p.43 및 Table 9 p.46. 모두 문서 표기와 PDF 페이지가 같다.
- [AT044 공급사 자료](https://www.devicemart.co.kr/goods/view?no=1361352)의 상세 이미지에서 VCC/TXD/RXD/GND, A+/B-/접지 단자를 확인했다. 3.3V 지원·자동 방향 제어·R0 단락 시 120Ω 종단 활성화 설명을 확인했다. 공급사 이미지에 TXD/RXD 입출력 방향을 명시한 회로도는 없어 실제 모듈의 방향 대조는 남아 있다.
- 전원은 NUCLEO 3.3V→VCC, GND→TTL 쪽 GND로 제안한다. 신호선은 AT044 TXD가 입력, RXD가 출력인 경우 PB6→TXD, RXD→PB7로 연결한다. PC 쪽은 A+↔A+, B-↔B- 기준이며 실제 USB 변환기 모델·단자 확인은 남아 있다.
- 현재 USART1 펌웨어 구현·전원 인가·배선 완료·통신 성공은 기록하지 않는다. 이번 안내는 전원을 분리한 상태의 배선 준비다.
